## My Next Project

It's been a minute since I've made a devlog, honestly because I haven't really been developing that I'd consider that interesting as of late. However I've decided on my next project - A full stack webapp for the Minecraft server I play on with my mates!

I had this random thought today that I wanted to make a website for my Minecraft server where my mates can share interesting stories and upload screenshots, while also just providing general information about the server such as if it's online, how many players are currently online, the world map etc.

I'll also be adding a feature where people can request to join through the website and I can choose to whitelist them into the server. I think this will be cool project and will be the first project where I've technically got users to test it out :)

## The Stack

This is a full stack app, meaning it does have a frontend, backend and a database.

The frontend stack consists of:

- React
- TypeScript
- TanStack Query
- Tailwind CSS
- Zod

The backend stack consists of:

- Go
- SQLC
- Goose
- PostgreSQL
- Discord OAuth

Now for this project, I'm also dipping my toes to agentic development. I don't like frontend work (mainly cause I'm not good at it), so basically all my frontend code will be AI generated. I'm still extensively reviewing the code and making sure I understand it, either way this project isn't that conceptually sophisticated anyway and I believe everything on the frontend side I could hand-code myself, would just take me a LOT longer to get it how I want it.

All the backend code will be hand written by me, though I'm still using AI there to review and discuss the decisions and patterns I'm using.

As you've probably seen, I'm personally interested in and pursuing backend/data engineering so using AI extensively in the frontend doesn't bug me. I'm still hand writing the backend because I want to make sure I have all the fundamentals down now so hopefully when I start working in the industry I can, using AI as a tool, increase the velocity in which I ship good code.

Anyway, I'm really excited about this project, I'll hopefully have some more devlogs coming out about it in the near future!
