## Trail

The goal for Trail was honestly for me to have a project to do while learning Rust. Trail is my first real Rust project and I went into it without much knowledge of it to be honest, but I think I came out of it a lot more confident in my Rust programming ability. The reason why I chose go with Rust as the next language I wanted to learn was for a few reasons. Rust is currently really popular, I feel like everyday you hear abut someone doing another full rewrite/refactor into Rust because of how efficient you can make programs in Rust. Another reason is because I want to go into infrastructure/systems engineering, so I want to learn the popular languages in this field specifically. The languages I kept seeing were Go and Rust. I think I'm pretty competent when it comes to programming in Go, so I thought I'd pick up Rust as well.

Trail is a keyboard driven TUI. The reason why is because that's where I mostly do my work. I use Neovim as my editor, I'm pretty quick navigating the terminal, so it just made sense to build the app to best fit my workflow. I later added mouse support though, since at the end of the day I do want it to be something that most people can use without much hassle.
